# Как включить экзамен

Сейчас режим **«Экзамен»** в обоих предметах (СУБП и Человеческий фактор)
помечен как **«на стадии разработки»** и заблокирован. Тренажёр работает.

Когда захотите подключить экзамен — это **одна правка флага**.

## Шаги

1. Откройте файл `app.js`, строка 4 (в самом верху):
   ```js
   const EXAM_ENABLED = false;
   ```
   Поменяйте на:
   ```js
   const EXAM_ENABLED = true;
   ```

2. Откройте файл `sw.js`, строка 2 — поднимите номер версии кэша
   (любое новое число, иначе у пользователей останется старая версия из офлайн-кэша):
   ```js
   const CACHE = 'subp-trainer-v12';   →   'subp-trainer-v13'
   ```

3. Отправьте изменения на сайт. В папке `subp-trainer` выполните:
   ```
   git add -A
   git commit -m "Экзамен включён"
   git push origin main
   ```
   Сайт https://bsheraliev.github.io/subp-trainer/ пересоберётся за ~1 минуту.

## Что произойёт

- С кнопки «Экзамен» исчезнет бейдж «в разработке».
- Вместо заглушки 🛠️ снова появятся карточки для входа в экзамен.
- Вся логика экзамена (таймер 20 мин, 25 вопросов, проходной 75 %, справка,
  журнал прохождений) уже готова и проверена — флаг только прячет вход.

## Чтобы снова отключить

Верните `const EXAM_ENABLED = false;`, поднимите версию в `sw.js`, запушьте.

---
*Можно вместо ручной правки просто написать Claude: «включи экзамен» — он сделает эти шаги.*
