# Тренажёр СУБП

Учебное веб‑приложение (PWA) для подготовки авиационного персонала по **Системе управления безопасностью полётов (СУБП / SMS)**.
Основа: ИКАО Приложение 19, Doc 9859.

## Возможности
- **Тренажёр** — практика по категориям с мгновенными пояснениями.
- **Экзамен** — 25 вопросов (10 профильных + 15 общих), таймер 20 минут, проходной 75%.
- Категории: Диспетчер УВД, Лётный экипаж, ИТП (вкл. бортинженеров), Кабинный экипаж, Общий блок.
- Банк — 105 вопросов.
- Ввод ФИО, **справка о прохождении** с печатью/PDF, **журнал прохождений** на устройстве.
- Устанавливается как приложение (PWA), работает офлайн.

## Запуск
Открыть `index.html` в браузере или разместить на любом статическом хостинге (GitHub Pages).
