# Авиатренажёр · СУБП и Человеческий фактор

Учебное веб‑приложение (PWA) для подготовки авиационного персонала. Два предмета на выбор:
- **СУБП** — Система управления безопасностью полётов (ИКАО Приложение 19, Doc 9859).
- **Человеческий фактор** — модели и ошибки, человек и нагрузка, эргономика (ИКАО Doc 9683).

## Возможности
- **Выбор предмета** на стартовом экране: СУБП или Человеческий фактор.
- **Тренажёр** — практика по разделам с мгновенными пояснениями.
- **Открытые вопросы (развёрнутый ответ)** — обучаемый пишет ответ своими словами; его оценивает **ИИ** (балл 0–100, вердикт, что стоит добавить) с показом эталона. Без подключённого ИИ работает локальная проверка по ключевым словам. Открытые вопросы доступны в «Тренажёре».
- **Экзамен** — 25 закрытых вопросов, таймер 20 минут, проходной 75% (открытые вопросы в экзамен не входят). Старт — **после ввода данных и персонального одобрения**: по нажатию «Начать» экзаменатору в **Telegram** приходят данные кандидата и персональный одноразовый код; экзаменатор диктует код кандидату, тот вводит его — экзамен начинается. Код действует 15 минут. Работает на существующем боте (без webhook).
  - СУБП: 10 профильных + 15 общих (по выбранной категории персонала).
  - ЧФ: единый итоговый экзамен — 25 вопросов по всему курсу.
- Разделы СУБП: Диспетчер УВД, Лётный экипаж, ИТП (вкл. бортинженеров), Кабинный экипаж, Сотрудники аэропорта, Общий блок.
- Разделы ЧФ: Модели и ошибки (SHELL, Ризон, «грязная дюжина», культура справедливости), Человек и нагрузка (внимание, усталость, стресс, надёжность), Эргономика рабочего места.
- Банк — **263 вопроса** (СУБП 193, ЧФ 70), из них **39 открытых** с ИИ-проверкой (равномерно 4–5 открытых на раздел, много сценариев из практики).
- Ввод ФИО, **справка о прохождении** с печатью/PDF, **журнал прохождений** на устройстве.
- Устанавливается как приложение (PWA), работает офлайн.

## ИИ-проверка открытых ответов
Работает «из коробки»: в приложение вшит эндпоинт по умолчанию (Google Apps Script,
Groq gpt-oss-120b + Gemini, ключи на стороне сервера, 0 токенов Claude). Можно указать свой
эндпоинт кнопкой «⚙ ИИ-проверка открытых ответов» (пусто — встроенный по умолчанию). Если
ИИ недоступен — локальная проверка по ключевым словам. Файл и инструкция —
`материалы/ai-check.gs` и `материалы/КАК-ПОДКЛЮЧИТЬ-ИИ-ПРОВЕРКУ.md`.

## Запуск
Открыть `index.html` в браузере или разместить на любом статическом хостинге (GitHub Pages).
